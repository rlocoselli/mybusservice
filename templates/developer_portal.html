Como usar

  1. Crie uma conta, entre e gere uma chave com um nome que identifique seu projeto.
  2. Envie a chave no cabeçalho X-API-Key de cada consulta HTTPS. Nunca coloque a chave na URL nem no código público do navegador.
  3. Se ela for exposta, revogue-a aqui e gere outra.
curl -H 'X-API-Key: SUA_CHAVE' \
  https://mybusaoservice.audeladedonnees.fr/getRoutes/Grenoble_France

As chaves só autorizam consultas de dados de transporte. O dashboard e a administração exigem uma conta administrativa separada. Para aplicações web públicas, guarde a chave no servidor e faça as chamadas por ele.
